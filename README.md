# Connectly 💬

A simple full-stack chat application built to explore web development and client-server communication.

## Features

- Simple and user-friendly chat interface
- Frontend and backend integration
- Messaging functionality

## Project Structure

```text
Connectly/
├── backend/
├── frontend/
├── .gitignore
└── README.md
```

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/ALANSAMUVEL/Connectly.git
cd Connectly
```

**2. Set up the backend**

```bash
cd backend
npm install
npm start
```

**3. Set up the frontend**

Open a new terminal:

```bash
cd Connectly/frontend
npm install
npm run dev
```

**4. Open the application**

Visit the local URL displayed in your frontend terminal.

## Technologies

This project uses separate frontend and backend components to build a web-based chat application.
